# SwiftRun · 校园跑腿互助平台

纯 HTML + CSS + 原生 JavaScript 的单文件单页应用，无外部依赖、无后端，所有数据由前端数组模拟。

## 运行

用浏览器直接打开 `index.html` 即可，也可以放到任意静态托管上。

## 功能

- **顶部导航**：当前用户信息（头像、姓名、学院、已完成单数）与信用分，完成任务时信用分有跳动反馈
- **发布任务**：标题、描述、报酬三个字段，逐字段校验 + 常用报酬（¥5/¥10/¥15/¥20）快捷填入
- **任务大厅**：卡片列表展示全部任务，支持「全部 / 待接单 / 进行中 / 已完成 / 我发布的」筛选
- **接单流转**：待接单 → 进行中 → 已完成，按钮文案随状态变化，自己发布的任务不可自己接
- Toast 轻提示、空状态提示、响应式布局（360px 宽度起可用）

## 当前实现的约定

题目没有规定的地方，这里做了如下约定：

- 信用分初始 95，每完成一单 +2，封顶 100；接单不加分
- 标题 2–30 字，描述 5–120 字，报酬 0–200 元
- 数据仅存在内存中，刷新页面会回到种子数据（没有接后端或本地存储）

## 技术说明

- 单文件 `index.html`，CSS 与 JS 内联，无外部依赖、无网络请求
- 用户输入一律通过 `textContent` 写入 DOM，不会被当作 HTML 解析
- 调试入口：控制台可通过 `window.CampusRun` 访问 `tasks` / `state`，或调用 `acceptTask` / `finishTask` / `setFilter`
